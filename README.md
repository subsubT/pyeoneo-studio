# 평어담

초등 교사가 실제 활동에 근거한 교과 평가 평어를 검토하고 승인·조합·XLSX로 저장하는 한국어 웹앱.

**공개 서비스: AI 비활성 개발 버전. 로컬: NVIDIA DeepSeek V4.1 Flash 생성·검증 시험 지원.** 실제 활동과 예시를 입력하고 직접 작성한 후보를 관리하는 기능은 공개 서비스에서 사용할 수 있습니다.

## 실행
Node.js 22 이상. `npm ci`, `npm run build`, `npm start`. 개발 모드 `npm run dev`. 단위 검사 `npm test`.

로컬 AI 시험은 프로젝트 루트의 Git 제외 파일 `.env.local`에 `NVIDIA_API_KEY`를 설정한 뒤 `npm run dev:ai`로 실행합니다. 주소는 `http://127.0.0.1:3005`입니다. 환경 파일의 기존 값은 유지합니다. `npm run test:ai`는 작성된 가상 활동만 보내는 실모델 시험입니다. `npm test`는 네트워크 호출 없는 검사입니다. `npm run dev`와 production 실행에서는 AI가 꺼집니다.

로컬 요청은 단계별 0~24개·합계 1~24개, 생성 후 별도 의미 검토, 동시 1회·프로세스별 시간당 12회로 제한합니다. 기본 승인 목표는 24개이며 교사 확인 없이는 승인되지 않습니다. 입력은 32KB, 공급자 응답은 256KB, 1회 호출은 180초로 제한하며 자동 재시도하지 않습니다. 로컬 제한은 공개 운영의 비용 통제 수단이 아닙니다.

## 기능
- 50MB/30쪽 이하 텍스트 PDF 분석. 제공된 1학년 평가 계획 서식 지원. 다른 서식은 원문 참고 직접 입력, 스캔 PDF OCR 미지원.
- 두 단계: 평가계획 추출·검토·선택·확정 → 실제 활동 확인·문장 생성·검토·승인·내보내기.
- 교과별 전체 선택·해제, 개별 항목 제외·재선택, 누락 항목 추가. 제외한 항목과 문장은 작업에 보관하고 선택한 항목만 문장 작업·XLSX에 전달.
- 교과·단원·성취기준·평가 요소·방법·사용자가 설정한 단계별 기준 직접 편집. 원본 PDF 쪽과 추출 원문을 나란히 대조. 모르는 기준은 빈칸으로 남기고 미분류 원문을 보존.
- 원본 XLSX 예시를 브라우저에서 읽고 원문 보존. 자료를 공개 저장소/서버에 올리지 않음.
- 계획과 실제 수행 사실 분리. 단계별 생성 개수, 항목별 승인 목표 24개 기본.
- 내부 금지 어휘·사실·의미·중복 검사, 목록 전체 교사 확인과 일괄 승인. 특정 종결형 강제 없음. 승인 문장만 출력.
- 동일 교과 승인 문장 조합, 교과별/항목별 XLSX, 로컬 작업 JSON 저장·복원.
- 창을 닫으면 메모리 작업 소멸. 원본 PDF·추출 원문·편집 계획·선택/확정 상태를 v2 작업 JSON으로 저장·복원(최대 200MB, 100항목, PDF 10개). 기존 v1 파일도 열 수 있음. 복원 문장은 재검토·승인 필요.
- 작업 파일은 현재 작업에 추가로 열며, 출처 ID를 새로 부여해 여러 PDF의 쪽수를 혼동하지 않음. 기존 작업과 합치면 계획을 다시 확정.

## 개인정보와 운영
실명이나 학생 개인정보를 요구하지 않습니다. PDF/XLSX와 결과는 브라우저에서 처리하고 DB는 사용하지 않습니다. 공개 AI API는 503으로 닫혀 있습니다. 로컬 AI 시험을 명시적으로 실행하면 선택 항목의 실제 활동·예시·수준·기존 문장만 NVIDIA에 전송합니다. PDF 전체나 원본 XLSX는 전송하지 않습니다. 키는 서버에서만 읽고 요청·응답 원문을 서버 로그에 기록하지 않습니다. 공개 운영 연결에는 별도 이용 조건 및 분산 비용 통제가 필요합니다.
