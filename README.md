# 평어담

초등 교사가 실제 활동에 근거한 교과 평가 평어를 검토하고 승인·조합·XLSX로 저장하는 한국어 웹앱.

**현재 상태: AI 연결 전 공개 개발 버전. 자동 생성은 아직 사용할 수 없습니다.** 실제 활동과 예시를 입력하고 직접 작성한 후보를 관리하는 기능은 사용할 수 있습니다.

## 실행
Node.js 22 이상. `npm ci`, `npm run build`, `npm start`. 개발 모드 `npm run dev`. 단위 검사 `npm test`.

## 기능
- 10MB/30쪽 이하 텍스트 PDF 분석. 제공된 1학년 평가 계획 서식 지원. 다른 서식은 원문 참고 직접 입력, 스캔 PDF OCR 미지원.
- 원본 XLSX 예시를 브라우저에서 읽고 원문 보존. 자료를 공개 저장소/서버에 올리지 않음.
- 계획과 실제 수행 사실 분리. 4단계 수준, 항목별 승인 목표 24개 기본.
- 금지 어휘·함. 종결·길이·중복 검사, 교사 최종 확인. 승인 문장만 출력.
- 동일 교과 승인 문장 조합, 교과별/항목별 XLSX, 로컬 작업 JSON 저장·복원.
- 창을 닫으면 메모리 작업 소멸. 작업 파일을 내려받아 이어서 사용. 복원 문장은 재검토·승인 필요.

## 개인정보와 운영
실명이나 학생 개인정보를 요구하지 않습니다. 현재 파일/내용은 브라우저에서만 처리합니다. DB는 사용하지 않습니다. AI API는 503으로 닫혀 있고 외부 전송하지 않습니다. 향후 운영 AI를 연결하려면 서버 비밀값과 분산 호출량/비용 제한 및 실모델 검증을 먼저 구현해야 합니다.

자세한 현황: [개발 상태](docs/STATUS.md), [AI 운영 설계](docs/AI-OPERATIONS.md).

첨부된 참고 파일은 저장소에 포함하지 않습니다. 교육 자료 및 개인정보를 이슈·커밋에 올리지 마세요.
