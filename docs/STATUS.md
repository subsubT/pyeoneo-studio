## 체크포인트 1: 자료 분석·기본 화면

- 첨부 서식의 열 구조 기준으로 분석. 다른 서식은 추출 원문과 직접 입력 지원. 스캔 문서 OCR 미지원.
- 원본 XLSX는 교과별 시트, 항목별 열, 문장 사이 여백 방식 참고. 원본은 저장소에 포함하지 않음.
- 실제 활동은 빈 칸으로 시작하고 별도 확인 필요. 추출된 계획을 사실로 전용하지 않음.
- PASS: production build 성공. 공개 브라우저에서 실제 PDF 16개 항목 및 XLSX 원본 예시 168개 불러오기 확인.
- 2026-10-27: 평가 기준을 네 수준별 설명으로 분리하도록 수정. 실제 PDF 16개 항목의 64개 기준을 확인.

## 체크포인트 2: AI 생성·검증
- 4단계, 목표 기본 24/최대 120, 후보 12개 상한, 생성과 별도 의미 검토를 수행하는 공급자 독립 로직 구현.
- 금지 표현, 종결, 길이, 중복, 근거 문자열, 검토 응답 누락 검사: 단위 테스트 PASS.
- 색 혼합 추가/핵심 활동 누락 사례: 모의 공급자로 거부 흐름 검증. 실제 모델의 품질을 검증했다는 의미는 아님.
- 실제 AI 어댑터 미연결. API GET enabled=false, POST 503. 비밀키와 외부 전송 없음.
- 자동 승인 검토에서 NVIDIA 전송 및 소유 미정 호출 제한 서비스 연결이 거부되어 보류.
- NVIDIA 무료 체험 약관은 내부 테스트·평가용으로 운영 사용 제한. 운영 연결 전 계약·제공사·전송 범위 결정 필요.

## 체크포인트 3: 승인·조합·내보내기
