## 미실행·미해결·복구

- **필수 기능 미완료 없음.** 전체 Gemini/Upstash 사전 검사, 별도countTokens, 실서비스 부하/RPM·450회 소진 시험은 재실행하지 않음(기존 근거 재사용·불필요 호출 방지). 기존 자동/모의 한도·429/503 회귀와 이번 실제7시도의 공유 예산 통과를 구분한다. 이번 실제503/429는 발생하지 않았으며 모의 결과를 실제 관찰로 보고하지 않는다.

- **rollback/전역 비활성화/카운터 삭제 없음.** 같은 작업에서 오류 수정·push·Production 재배포·공개 검증으로 정상화. 초기 정상 복구 대상은 위에 기록했으며 복구 실행이 없어 복구 후 검사 N/A. 두 활성 플래그/공유 stop·무료 플랜·키·salt 보존.
