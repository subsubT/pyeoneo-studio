자동 검사 통과는 교사 승인과 다르다. 형식·금지어·중복·근거 확인에서 탈락한 후보는 표시하고 제외하며, 유효 후보는 별도 모델 호출로 의미를 검토한다. 최종 승인은 교사가 수행한다. 색은 수정 후 재시험, 수 비교/도움 필요는 최초 시험 결과다. 낱말은 최초 확인 결과를 보수적으로 남겼고 후속 검토 상태는 TIMEOUT이다. 검토 재시도에는 이미 받은 실제 생성 응답을 재사용했다.

색 혼합 실험, 별도 작품 제작, 친구 작품 감상, 색상환 완성 누락, 협력 행동 추가를 넣은 부적합 문장 5/5 거부. 실제 활동만 담은 대조 문장 1/1 통과. 이는 마지막 성공한 시험 결과이며, 검토 지침 보완 후 최신 재검사 상태는 TIMEOUT이다. 시간 초과를 통과로 처리하지 않는다.

처음 색 시험은 12개 중 8개 통과, 낱말 시험은 종결 등의 이유로 0개 통과했다. 근거가 문자열로 온 후속 응답도 전체 차단했다. 수정 후에는 단일 근거 문자열만 배열로 표준화하고 정확한 입력 근거 검사를 유지했다. 종결 지침과 동일한 활동을 표현한 문장의 검토 지침을 보완했다. 부적합 후보를 자동 수정·승인하지 않는다.

기록된 CLI 성공 호출 15회: 입력 10002 / 출력 6595 / 전체 16597 토큰. 브라우저 시험 2회 및 초기 시간초과 요청은 이 집계에 포함하지 않았다. 성공 호출 시간 77377~116311ms. 대기 시간이 길어 공개 운영의 응답성을 검증했다는 의미는 아니다.
